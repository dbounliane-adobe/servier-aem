# topic-cards

Custom **topic-cards** block. Purpose: cards-topics.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: optional image (+alt), heading, description, link (Découvrir).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
