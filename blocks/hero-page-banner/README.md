# hero-page-banner

Custom **hero** block. Purpose: page-banner.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 banner image (+alt); row 2 rich text with the card heading (e.g. h2 'Retrouvez nos <strong>décryptages</strong>'); optional list of links in row 2 overrides the automatic breadcrumbs (Accueil > parent > current page title).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
