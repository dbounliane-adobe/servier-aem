# carousel-stories

Custom **carousel** block. Purpose: carousel-patient-stories.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image (+alt) cell, rich-text cell with h2, paragraph, Lire la suite link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
