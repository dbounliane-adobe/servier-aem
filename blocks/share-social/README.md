# share-social

Custom **share** block. Purpose: social-share.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row: label text. Network links (Facebook, X, LinkedIn, copy link; optional email) are generated in JS from the canonical URL / og:title..

## Supported variations

| Variation | Option class |
| --- | --- |
| Add email link | `email` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: Add email link.
