# article-list

Custom **cards** block. Purpose: newsroom-dossiers-listing.

## Authoring (Document Authoring)

Model: `configuration`

Key/value rows (label in the first cell, value in the second): key-value configuration: source index, path prefix, page size, enabled filters, filter UI labels, read-more label, empty/no-results/error messages, optional subscribe link + label.
