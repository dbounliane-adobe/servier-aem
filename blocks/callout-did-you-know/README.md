# callout-did-you-know

Custom **callout** block. Purpose: callout.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 label text ('Le saviez-vous ?'); row 2 rich text (paragraphs with footnote superscripts). A single row with two cells [label | text] is also accepted..
