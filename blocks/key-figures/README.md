# key-figures

Custom **key-figures** block. Purpose: key-figures.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: container with repeating key-figure items; each item row has 2 cells: value (e.g. 1,6), label (description).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- A separate `-item` model defines one repeated item.
